# -Firewall-Traffic-Control-and-Forensic-Verification

<h1>Gabriel - Firewall-Traffic-Control-and-Forensic-Verification </h1>



<h2>Description</h2>
Explain host-based and network-based firewalls; interpret INPUT/OUTPUT/FORWARD chains; safely add, verify and remove a narrow iptables rule; compare allowed and blocked HTTP captures; correlate counters, retransmissions and client behaviour; explain DROP versus REJECT.
<br />

- <b>Kali Linus </b> 


<h2>Environments Used </h2>

- <b>Windows 11</b> (21H2)
